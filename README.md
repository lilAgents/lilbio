# lilBio

Brand Copy Locker

Write your bio once in every length, then copy the right version for every platform with character limits checked. Everything is saved in your browser.

Part of [Hot App Summer](https://hotappsummer.netlify.app) by [lilAgents](https://lilagents.com): one small, useful web tool shipped every day through June.

## Run it locally

This is an [Astro](https://astro.build) site.

```bash
pnpm install
pnpm dev
```

To build for production:

```bash
pnpm build
```
